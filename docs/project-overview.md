# Project Overview

## Purpose
This portal enables organizations to comply with India's DPDPA by providing:
- Granular consent management for data principals
- DSAR (Data Subject Access Request) submission and tracking
- Admin workflow for processing requests
- Immutable audit logging

## User Roles
- **User (Data Principal)**: Can grant/revoke consents, submit and track DSARs
- **Admin (Data Fiduciary)**: Can manage all DSARs, view audit logs

## Request Types
| Type | Description |
|------|-------------|
| access | Request a copy of personal data |
| correction | Request correction of inaccurate data |
| erasure | Request deletion of personal data |
| portability | Request data in machine-readable format |
| nomination | Nominate a person to exercise rights |
